# Research and decision record

The sponsor requested 50 repositories narrowed to ten, plus similar developers, with five contributions planned for each selected repository. The sponsor corrected the first audit: the desired reference is early OmniRoute, a practical individually led product receptive to substantial outside work. Institutional prestige and a CONTRIBUTING file alone do not demonstrate that property.

## Sponsor requirements preserved

- Discovery preference: 100-1,000 stars very early; 2,000-10,000 early; 10,000-50,000 already popular and the ceiling. Retain 1,001-1,999 as a separately recognized gap band, not silently categorized as 100-1,000.
- Find fifty candidates, then ten starting repositories. At least three should directly support current work or be personally useful.
- Evaluate PR types accepted, practical brand/business value, resume experience, and similar developers.
- Use subagents, investigate actual receptiveness, and correct the initial institutional shortlist.
- Latest authorization: plan five PRs for every selected repo, document the work, and push to phenotype-registry. Upstream submissions are a later action.

## Boundaries and overlap

Canonical documentation owner: phenotype-registry. Canonical implementation owners: the ten upstream repositories listed in the overview. No code is being consolidated or copied across them. The per-repository plans record current source inspection and overlapping issues/PRs; repeat those checks against the current head before implementation.

No source retirement, archive, boundary transfer, or fork deletion is involved. No sibling upstream PR exists from this program yet. Private employment relationships among contributors are unknown; a non-owner GitHub association is only a practical public proxy for outside contribution.

## Selection rationale

Prefer demonstrated substantial outside merges, owner help with integration, useful features we can dogfood, and finite review effort. The first cohort is KeiRouter, token-monitor, Octopus, and Lynkr. Secondary cohort: gpt-load, macparakeet, DeskcommCRM, Atlas, jayjay. CCProxy remains conditional on current responsiveness. Public star totals cannot predict a breakout.
