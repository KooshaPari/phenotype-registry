## 1. Branch protection on main (Effort: S, Risk: Low)
Lock main branch to require 2 PR reviews; disable force-push. Workflow friction only.

## 2. Manual release playbook (Effort: M, Risk: Low)
Document GPG tag + changelog + smoke test process. Process debt until CI restored.

## 3. cargo-deny license audit pass (Effort: M, Risk: Med)
Run manual `cargo-deny check licenses` per repo; pin incompatible crates or swap deps. Distribution may block if conflicts found.

## 4. Security response playbook (Effort: M, Risk: Low)
Draft escalation matrix + embargo timeline. Preparation gap until written.

## 5. Mirror repos to Codeberg/GitLab nightly (Effort: S, Risk: Low) ⭐
Cron-driven mirror via local runner (not Actions). Mitigates billing/lock-in risk. **Recommended high-leverage move.**

## 6. DCO enforcement (Effort: S, Risk: Med)
Signed-off-by in PR template; verify at merge. Retroactive relicensing risk if missed.

## 7. Mandatory client-side pre-commit (Effort: S, Risk: Low)
Document install steps. Quality gate absent CI runs.

## 8. ADRs for critical decisions (Effort: L, Risk: Low)
Author ADRs for persistence, API design. Bus-factor reduction.
