## Commands Run

The user-provided command shape was checked first. Current `gh pr list` does not expose a
`repository` JSON field and the sample `jq` expression needs `fromdateiso8601` for ISO timestamps,
so the org-wide equivalent used `gh search prs` and the GitHub Search API.

```bash
gh search prs --owner KooshaPari --archived=false --state=open \
  --sort updated --order asc --limit 30 \
  --json number,title,repository,updatedAt,createdAt,url
```

```bash
gh api -X GET search/issues \
  -f q='user:KooshaPari is:open is:pr archived:false' \
  -f sort=updated -f order=asc -f per_page=30 \
  --jq '{total_count, items: [.items[] | {repo:(.repository_url|split("/")[-2:]|join("/")), number, title, created_at, updated_at, url:.html_url}]}'
```
