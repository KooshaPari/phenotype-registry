## Background

The program goal was simple: make cargo-deny a default supply-chain guardrail by landing `deny.toml` and `.github/workflows/cargo-deny.yml`, then adding `workflow_dispatch` where needed so the check could run on demand as well as on schedule. The cleanest session-end framing says the program reached 40/42 enrolled repos and 40/40 active repos, with archived repos excluded from the active denominator. [CARGO_DENY_ROLLOUT_FINAL_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_ROLLOUT_FINAL_2026_04_27.md) [CARGO_DENY_VICTORY_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_VICTORY_2026_04_27.md)

The baseline, however, was much weaker. The corrected local truth probe across 42 local Rust repos found only 18 repos with `cargo-deny.yml`, only 5 with `workflow_dispatch`, and 24 missing the workflow entirely. That local probe also found 35 repos with `deny.toml`, which matters because workflow presence and policy-file presence are not the same thing. [CARGO_DENY_TRUE_COVERAGE_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_TRUE_COVERAGE_2026_04_27.md) [CARGO_DENY_LOCAL_TRUTH_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_LOCAL_TRUTH_2026_04_27.md)

The rollout itself was branch-driven: 27 branches were prepared, with 21 full-rollout branches adding both `deny.toml` and the workflow, and 6 branches only adding `workflow_dispatch`. [CARGO_DENY_ROLLOUT_FINAL_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_ROLLOUT_FINAL_2026_04_27.md)

## Methodology

- Treat local clones as the source of truth for repo presence and file presence, not GitHub contents metadata. The local probe explicitly excluded archive and worktree paths, enumerated 42 Rust repos, and avoided GitHub API calls. ## Audit-decay incidents

- The first major decay event was scope drift. One audit claimed 36 active Rust repos and 100% coverage, but the corrected local probe found 42 local Rust repos with only 18 `cargo-deny.yml` files and 5 `workflow_dispatch` triggers. [CARGO_DENY_COMPLETION_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_COMPLETION_2026_04_27.md) [CARGO_DENY_LOCAL_TRUTH_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_LOCAL_TRUTH_2026_04_27.md)
- The second decay event was the GitHub contents false-positive bug. The corrected audit says `gh api repos/.../contents/<file>` could return empty content rather than a clean 404 signal, which made missing workflows look present or dispatch-capable in earlier dashboards. [CARGO_DENY_TRUE_COVERAGE_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_TRUE_COVERAGE_2026_04_27.md)
- The third decay event was repo-count inflation. A GitHub-metadata-based audit reported 61 Rust-scope repos, 17 repos with `cargo-deny.yml`, 10 with `workflow_dispatch`, and 44 `NO_FILE` repos; the local-truth pass corrected that to 42 repos, 18 with `cargo-deny.yml`, 5 with `workflow_dispatch`, and 24 missing the workflow. [CARGO_DENY_LOCAL_TRUTH_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_LOCAL_TRUTH_2026_04_27.md)
- The fourth decay event was the gap between rollout success and live verification. The rollout docs show structural progress to 40/42 enrolled and 40/40 active, but the live verification note says every one of the 42 triggered runs was blocked by GitHub Actions billing, so no clean runtime verdict existed yet. ## Lessons learned

- Local clone truth beats content metadata for file-presence questions. The missing-file false positive came from relying on GitHub contents behavior instead of checking the actual checked-out repo state. [CARGO_DENY_TRUE_COVERAGE_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_TRUE_COVERAGE_2026_04_27.md)
- Enrollment, dispatchability, and run health are distinct states. A repo can have a workflow file, have `workflow_dispatch`, and still fail the actual cargo-deny job on license, manifest, or dependency issues. [CARGO_DENY_LOCAL_RUN_RESULTS_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_LOCAL_RUN_RESULTS_2026_04_27.md) [CARGO_DENY_LIVE_RESULTS_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_LIVE_RESULTS_2026_04_27.md)
- Real cargo-deny output is useful signal, not just wiring noise. In the local sample, the failures were concrete: license rejection, unlicensed crates, duplicate keys, missing packages, and manifest parse errors. [CARGO_DENY_LOCAL_RUN_RESULTS_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_LOCAL_RUN_RESULTS_2026_04_27.md)
- Branch-content audits should be separated from PR creation state. The rollout branches themselves were clean in the sampled audit, while PR creation still failed for expected reasons such as already-open PRs, blank head/base SHAs, or no-op branches. [CARGO_DENY_BRANCH_CONTENT_AUDIT_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_BRANCH_CONTENT_AUDIT_2026_04_27.md) [CARGO_DENY_PR_CREATION_RESULTS_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_PR_CREATION_RESULTS_2026_04_27.md)
- The strongest operational pattern is to keep the evidence chain explicit: local truth, rollout branches, PR creation, and live verification each answer a different question. Collapsing them into one number creates the exact audit decay this program had to correct. [CARGO_DENY_TRUE_COVERAGE_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_TRUE_COVERAGE_2026_04_27.md) [CARGO_DENY_ROLLOUT_FINAL_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_ROLLOUT_FINAL_2026_04_27.md) [CARGO_DENY_LIVE_RESULTS_2026_04_27.md](/Users/kooshapari/CodeProjects/Phenotype/phenotype-org-governance/org-audit-2026-04/CARGO_DENY_LIVE_RESULTS_2026_04_27.md)
